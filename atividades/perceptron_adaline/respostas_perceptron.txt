[CONTEXTO DO PROBLEMA]

Perceptron de camada única é utilizado para classificar o óleo em duas classes 
de pureza:
  - Classe C1 (convenção -1)
  - Classe C2 (convenção +1)
Entradas: x1, x2, x3 (propriedades físico-químicas do óleo) e x0 = -1 (bias/limiar θ).
Algoritmo: Regra de Hebb supervisionada para classificação de padrões.
Configurações: Taxa de aprendizagem η = 0.01 | Função de ativação: Degrau Bipolar.

4. Explique por que o número de épocas de treinamento varia a cada vez que 
executamos o treinamento do perceptron.

RESPOSTA:
O número de épocas varia a cada execução porque os pesos iniciais do Perceptron 
são definidos aleatoriamente. 

O vetor de pesos inicial representa o ponto de partida do algoritmo no espaço 
de busca da solução. Como a regra de aprendizado do Perceptron (regra de Hebb 
supervisionada) ajusta o hiperplano separador iterativamente a cada erro cometidos:
1. Vetores de pesos iniciais mais próximos de um hiperplano separador válido 
   exigem menos modificações e, portanto, menos épocas para alcançar erro zero.
2. Vetores de pesos iniciais menos favoráveis necessitam de mais iterações de 
   ajuste no espaço de parâmetros.

Além disso, em conjuntos de dados linearmente separáveis, existem infinitos 
hiperplanos válidos que separam perfeitamente as duas classes. Cada vetor de 
inicialização conduz o algoritmo por uma trajetória diferente até encontrar 
um desses hiperplanos válidos.


5. Qual a principal limitação do perceptron quando aplicado em problemas de 
classificação de padrões.

RESPOSTA:
A principal limitação do Perceptron de camada única (Single-Layer Perceptron) é 
que ele só é capaz de resolver e classificar problemas cujos padrões sejam 
LINEARMENTE SEPARÁVEIS.

Isso significa que o Perceptron só consegue classificar corretamente se for 
possível traçar uma reta (em 2D), um plano (em 3D) ou um hiperplano (em N dimensões) 
que divida perfeitamente o espaço entre as duas classes.

Se o problema for NÃO LINEARMENTE SEPARÁVEL (como o problema clássico do XOR ou 
conjuntos de dados com distribuição sobreposta):
1. O algoritmo do Perceptron nunca converge (entra em loop infinito pois os erros 
   nunca chegam a zero).
2. Os pesos ficam oscilando indefinidamente.

Para solucionar problemas não linearmente separáveis, torna-se necessário utilizar 
redes neurais multicamadas (MLP - Multi-Layer Perceptron) com funções de ativação 
não lineares e algoritmo Backpropagation.
